# 固定宽度格式化器

一个用于模拟悬挂缩进效果的 Python GUI 工具，适合在不支持段落缩进的写字机器或简单文本编辑器中使用。

## 功能

- 将输入文字按固定宽度（以汉字数为单位）进行自动换行
- 用空格手动实现**悬挂缩进**：段首行不缩进，其余行在行首添加指定数量的空格
- 支持全角空格（`　`）和半角空格（` `），缩进数量支持 0.5 步进（0.5 = 追加一个半角空格）
- 字符宽度规则符合中文打字机惯例：
  - 汉字、假名等 → **2 列**
  - 中文标点（。，！？（）《》等）→ **1 列**（标点算半个字）
  - ASCII / 半角字符 → **1 列**
- 一键从剪贴板粘贴输入
- 一键复制格式化结果
- 导出为 UTF-8 编码的 `.txt` 文件

## 默认参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 行宽 | 24 汉字 | 每行最多容纳 24 个汉字（48 显示列） |
| 悬挂缩进 | 3.5 字符 | 续行缩进 3 个全角空格 + 1 个半角空格（共 7 列） |
| 空格类型 | 全角 | 缩进使用全角空格 `　` |

## 效果示例

输入（一段连续文字）：

```
这是一段测试文字，包含标点符号。我们来看看悬挂缩进的效果如何？希望一切正常！
```

输出（宽度 24 汉字，缩进 3.5 全角）：

```
这是一段测试文字，包含标点符号。我们来看看悬挂缩进
　　　 的效果如何？希望一切正常！
```

## 环境要求

- Python 3.9+（仅使用标准库：`tkinter`、`unicodedata`）

## 使用方法

```bash
python formatter.py
```

快捷键：`Ctrl+Enter` 执行格式化。
